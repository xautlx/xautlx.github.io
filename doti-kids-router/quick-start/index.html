1确认能不能装Check it can be installed

一点守护需要 OpenWrt 22.03 或更新的版本，最稳的是官方 OpenWrt。在路由器管理页 状态 → 概览 看「固件版本」，或者 SSH 登录后执行：Doti needs OpenWrt 22.03 or newer — official OpenWrt is the safest bet. Check “Firmware Version” under Status → Overview in the web admin, or run this over SSH:

cat /etc/openwrt_release
✓ 官方 OpenWrt 22.03 及以上（含 25.x）✓ Official OpenWrt 22.03+ (incl. 25.x)能直接装：同一页的「可用空间」要有 800KB 以上，不够会装不上。接着看第 2 步。Good to go — just make sure “Free space” on the same page shows at least 800KB, or it won’t fit. Then on to step 2.
? 基于新版 OpenWrt 的第三方或厂商固件? Third-party or vendor firmware built on recent OpenWrt如 ImmortalWrt 23.05、部分 GL.iNet 原装系统，一般能装，但没逐个测过：先按第 2–4 步试，第 4 步报错再刷官方版。e.g. ImmortalWrt 23.05 or some GL.iNet stock firmware — usually fine but not tested model by model: try steps 2–4 first, and reflash official OpenWrt only if step 4 fails.
✕ 不是 OpenWrt 的原装系统、21.02 及更早✕ Non-OpenWrt stock firmware, 21.02 or older要先刷官方 OpenWrt，见下面「需要先刷机？」。Reflash official OpenWrt first — see “Need to reflash?” below.
需要先刷机？Need to reflash?

建议刷 24.10 系列最新版（我们测过 24.10.8；它用 opkg 装软件，网上教程大多按它写）。25.x 改用 apk，也测过、同样支持。各型号刷机方法差别很大，请搜「型号 + OpenWrt 刷机」找教程。硬件至少要 16MB 存储、128MB 内存。We recommend the latest 24.10 release (tested on 24.10.8; it uses opkg, which most guides assume). 25.x uses apk and is supported too. Flashing differs a lot by model — search “your model + OpenWrt install”. You need at least 16 MB flash and 128 MB RAM.

⚠️
刷机有把路由器刷坏（变砖）的风险，建议用闲置的旧路由器，别拿家里正在用的那台试。Flashing can brick a router. Use a spare one, not the router your family relies on.

2接好路由器，用电脑登录Connect it and log in from a computer

用网线把光猫或原来路由器的 LAN 口，接到 OpenWrt 路由器的 WAN 口。原来的 WiFi 不受影响，家里其他设备照常用。接下来让电脑连这台 OpenWrt 路由器（网线插它的 LAN 口，或连它的 WiFi）。Run a cable from a LAN port on your modem or existing router to the WAN port of the OpenWrt router. Your existing WiFi isn’t affected. Then connect your computer to this OpenWrt router (cable into its LAN port, or join its WiFi).

光猫 / 原来的路由器 · LANModem / router · LAN──网线──WAN · 一点守护路由器WAN · Doti router

电脑连上这台路由器（网线或它的 WiFi），SSH 登录：Windows 打开 PowerShell，Mac 打开「终端」，执行下面的命令（地址按你的路由器改，OpenWrt 默认是 192.168.1.1）：Connect your computer to this router (cable or its WiFi) and SSH in — PowerShell on Windows, Terminal on Mac (OpenWrt’s default address is 192.168.1.1):

ssh root@192.168.1.1
  • 第一次登录会问 Are you sure you want to continue connecting，输入 yes 回车。First time, it asks Are you sure you want to continue connecting — type yes and press Enter.
  • 刚刷好的 OpenWrt 没有密码，问密码时直接回车；自己设过的就输入那个密码（输入时屏幕上不显示）。A freshly flashed OpenWrt has no password — just press Enter; otherwise type yours (it won’t show on screen).
  • 看到 root@OpenWrt 开头的提示，就是登录成功了。A prompt starting with root@OpenWrt means you’re in.
  • 连不上：光猫或原来的路由器也是 192.168.1.1 时会冲突。先拔掉这台路由器 WAN 口的网线，让电脑只连这台路由器再试；想一劳永逸，可以在管理页 网络 → 接口 把它的 LAN 地址改成 192.168.2.1 之类，再插回网线；改完电脑断开重连一次，以后都用新地址登录。Can’t connect? If your modem or old router is also 192.168.1.1 they clash. Unplug the cable from this router’s WAN port, keep your computer connected to this router and try again; for good, change its LAN address under Network → Interfaces to something like 192.168.2.1, plug the cable back in, reconnect your computer and use the new address from then on.
⏱️
路由器刚开机或刚刷完系统时，网络要一两分钟才就绪，稍等再进行下一步。Right after a reboot or a fresh flash, give the router a minute or two before the next step — its network is still coming up.

4安装一点守护Install Doti

第 3 步通过后，还在刚才的 SSH 里，执行下面这条命令。它会检查系统、下载最新版对应的安装包（22.03–24.10 用 ipk，25.x 用 apk）、校验后装好，升级程序也会自动补装：Once step 3 passes, in the same SSH session, run this. It checks the system, downloads the right package for it (ipk for 22.03–24.10, apk for 25.x), verifies and installs it; the updater installs itself too:

cd /tmp && wget -O install.sh https://gitee.com/xautlx/doti-kids-router/raw/main/install.sh && sh install.sh
⏱️
一般半分钟左右装好。提示「软件源更新失败」或缺组件时，回到第 3 步换镜像、更新通过后再执行一次。It usually takes about half a minute. If it says the feed update failed or something is missing, go back to step 3, switch mirrors, update until it passes, and run it again.

不想用命令行，就用电脑下载 doti-kids-router_all.ipk（在下面任一发布页的最新版里），再到路由器管理页上传。只适用于 22.03–24.10：25.x 的管理页只装有官方签名的包，请用上面的命令装。Prefer not to use the command line? Download doti-kids-router_all.ipk from the latest release on either page and upload it in the web admin. 22.03–24.10 only: on 25.x the web admin only installs officially signed packages, so use the command above.

5手机连上家长 WiFi，用小程序绑定Pair your phone in WeChat

装好 1–2 分钟后，会出现路由器的家长 WiFi，还没绑定时不用密码：1–2 minutes after installing, the router’s parents’ WiFi appears — no password until it’s paired:

DOTI-编号-ADMIN

手机连上它，打开微信小程序「一点守护」，按提示绑定路由器、给家长 WiFi 设个密码就好了；孩子的 WiFi 进小程序后按引导再连。Join it on your phone, open the “一点守护” mini program in WeChat, and follow the prompts to pair the router and give the parents’ WiFi a password; the mini program then walks you through connecting the kids’ devices.

微信里搜索「一点守护」Search WeChat for “一点守护”
✅
编号是路由器的 4 位编号，安装完成时命令行里会显示完整名字；一开始不用密码，绑定时会给它设上密码，名字不变。xxxx is the router’s 4-character code — the install command prints the full name when it finishes. It starts with no password; pairing adds one and keeps the name.
⏱
请在 30 分钟内完成绑定。为了安全，这个不用密码的 WiFi 只开 30 分钟，到时自动关闭；过了时间，把路由器断电再开，会再开 30 分钟。Finish pairing within 30 minutes. For safety, this open WiFi closes automatically after 30 minutes. If you miss it, power-cycle the router to get another 30 minutes.
🔑
路由器管理页的 root 密码：原来没设的，绑定后自动设成家长 WiFi 密码，以后改家长 WiFi 密码时一起改；自己设过的不动。家长 WiFi 密码随时能在小程序「路由器」页查看，它也是路由器管理页的密码。Router admin (root) password: if you never set one, pairing sets it to the parents’ WiFi password and keeps it in step when you change that password; one you set yourself is left alone. You can look up the parents’ WiFi password any time on the mini program’s Router page — it’s also the router admin password.
👉
接下来：跟着小程序给每个孩子设好 WiFi 和规则，孩子的手机、平板、电视连上自己的 WiFi，就开始管理了。Next: follow the mini program to set up each kid’s WiFi and rules. Once their phones, tablets and TVs join their own WiFi, Doti takes it from there.

?常见问题FAQ

更新软件源一直失败？Feed update keeps failing?
先确认路由器能上网；国内网络按第 3 步换成清华镜像再更新。Make sure the router is online; in China switch to the Tsinghua mirror (step 3) and update again.
安装命令报错、装不上？The install command fails?
多半是软件源没更新通过，回到第 3 步更新通过后再执行；剩余空间不足 800KB 的路由器也装不了。Usually the feeds weren’t updated — redo step 3 until it passes. Routers with under 800 KB free can’t install it.
搜不到 DOTI-编号-ADMIN？Can’t see DOTI-xxxx-ADMIN?
装好后要等 1–2 分钟；超过 30 分钟没绑定会自动关闭，把路由器断电再开就会重新出现。Give it 1–2 minutes after installing. It closes after 30 minutes if unpaired — power-cycle the router to bring it back.
