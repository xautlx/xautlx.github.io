自己安装一点守护Install Doti yourself

家里有闲置的路由器，就能自己装上一点守护。跟着下面几步做，系统合适的话大约 5 分钟；需要先刷机的，按型号另找教程。页面上的地址和命令都能一键复制。Have a spare router? You can install Doti on it yourself. With the right system it takes about 5 minutes; if it needs reflashing first, follow a guide for your model. Every link and command below has a copy button.

1确认路由器系统，不合适就先刷 OpenWrtCheck the router’s system — reflash if needed

一点守护要用 OpenWrt 22.03 起才有的新防火墙（firewall4），所以厂商原装固件、21.02 及更早的 OpenWrt 都装不上。旧路由器多数要先刷成官方 OpenWrt。先看看现在是什么系统：Doti needs the firewall (firewall4) that OpenWrt introduced in 22.03, so stock vendor firmware and OpenWrt 21.02 or older won’t work. Most older routers need to be reflashed with official OpenWrt first. Check what yours runs:

🧭
在现有系统上装：确认是官方 OpenWrt 22.03（2022 年 9 月发布）及以上就行，不用重刷。
打算全新刷机：建议刷 24.10 系列最新版（我们测试验证过 24.10.8）。它用大家熟悉的 opkg 装软件，网上的教程也大多按它写；固件选择器默认是最新版本，记得在版本里选 24.10。
25.x 改用 apk 装软件，我们也做过测试，同样支持。支持的最老版本 22.03、24.10 和 25.12，我们都在真机上做过安装和功能测试。Installing on the current system: official OpenWrt 22.03 (released Sep 2022) or later is all you need — no reflash.
Flashing from scratch: we recommend the latest 24.10 release (we’ve tested and verified 24.10.8). It installs software with the familiar opkg, which most guides online assume; the firmware selector defaults to the newest release, so pick 24.10 in the version list.
25.x switches to apk for installing software — we’ve tested it and it’s supported too. The oldest supported release (22.03), 24.10 and 25.12 have all been install- and feature-tested on real routers.
  • 管理页：状态 → 概览 里的「固件版本」Web admin: “Firmware Version” under Status → Overview

cat /etc/openwrt_release

2接好路由器，SSH 登录Connect it and SSH in

用网线把光猫或原来路由器的 LAN 口，接到 OpenWrt 路由器的 WAN 口。原来的 WiFi 照常用。Run a cable from a LAN port on your modem or existing router to the WAN port of the OpenWrt router. Your existing WiFi keeps working.

光猫 / 原来的路由器 · LANModem / router · LAN──网线──WAN · 一点守护路由器WAN · Doti router

电脑连上这台路由器（网线或它的 WiFi），SSH 登录：Windows 打开 PowerShell，Mac 打开「终端」，执行下面的命令（地址按你的路由器改，OpenWrt 默认是 192.168.1.1）：Connect your computer to this router (cable or its WiFi) and SSH in — PowerShell on Windows, Terminal on Mac (OpenWrt’s default address is 192.168.1.1):

ssh root@192.168.1.1
⏱️
路由器刚开机或刚刷完系统时，网络要一两分钟才就绪，稍等再进行下一步。Right after a reboot or a fresh flash, give the router a minute or two before the next step — its network is still coming up.

3更新软件源Update the package feeds必做required

一点守护的远程管理要用门铃组件 mosquitto-client-nossl，官方 OpenWrt 不自带，安装时要从软件源下载。所以先在 SSH 里更新一次软件源，确认路由器能连上软件源，通过了再做第 4 步，安装才能一次成功。按系统版本选一条：Doti’s remote management needs the doorbell component mosquitto-client-nossl. Official OpenWrt doesn’t ship it, so it’s downloaded from the package feeds during install. Update the feeds once in SSH to make sure the router can reach them, and only move on to step 4 once this passes — then the install succeeds first time. Pick the line for your release:

22.03–24.10opkgopkg
opkg update
25.xapkapk
apk update

✕ 没通过✕ Failed出现 Failed to download、ERROR 等：先确认路由器能上网；国内网络把软件源换成清华镜像（下面按版本选一条），再更新一次，直到通过。You see Failed to download, ERROR or similar: check the router is online. In China, switch the feeds to the Tsinghua mirror (pick the line for your release below) and update again until it passes.
换清华镜像 · 22.03–24.10Tsinghua mirror · 22.03–24.10
sed -i 's_downloads.openwrt.org_mirrors.tuna.tsinghua.edu.cn/openwrt_' /etc/opkg/distfeeds.conf
换清华镜像 · 25.xTsinghua mirror · 25.x
sed -i 's_downloads.openwrt.org_mirrors.tuna.tsinghua.edu.cn/openwrt_' /etc/apk/repositories.d/distfeeds.list
💡
软件源列表放在内存里，路由器重启后就没了。重启过的话，安装前再更新一次。The feed lists live in memory and are gone after a reboot — if the router restarted, update again before installing.

4安装一点守护Install Doti

第 3 步通过后，还在刚才的 SSH 里，执行下面这条命令。它会检查系统、下载最新版对应的安装包（22.03–24.10 用 ipk，25.x 用 apk）、校验后装好，升级程序也会自动补装：Once step 3 passes, in the same SSH session, run this. It checks the system, downloads the right package for it (ipk for 22.03–24.10, apk for 25.x), verifies and installs it; the updater installs itself too:

cd /tmp && wget -O install.sh https://gitee.com/xautlx/doti-kids-router/raw/main/install.sh && sh install.sh
⏱️
一般半分钟左右装好，门铃组件会随安装一起从软件源下载。提示「软件源更新失败」或缺组件时，回到第 3 步换镜像、更新通过后再执行一次。It usually takes about half a minute; the doorbell component is downloaded from the feeds as part of the install. If it says the feed update failed or something is missing, go back to step 3, switch mirrors, update until it passes, and run it again.

不想用命令行，就用电脑下载 doti_all.ipk（在下面任一发布页的最新版里），再到路由器管理页上传。只适用于 22.03–24.10：25.x 的管理页只装有官方签名的包，请用上面的命令装。Prefer not to use the command line? Download doti_all.ipk from the latest release on either page and upload it in the web admin. 22.03–24.10 only: on 25.x the web admin only installs officially signed packages, so use the command above.

5手机连上家长 WiFi，用小程序绑定Pair your phone in WeChat

装好 1–2 分钟后，路由器会开一个不用密码的临时家长 WiFi：1–2 minutes after installing, the router opens a temporary, password-free parents’ WiFi:

DOTI-TEMP-ADMIN

手机连上它，打开微信小程序「一点守护」，按提示绑定路由器、设置孩子的 WiFi。设置时会给这个 WiFi 改名并设上密码。Join it on your phone, open the “一点守护” mini program in WeChat, and follow the prompts to pair the router and set up the kids’ WiFi. Setup renames this WiFi and gives it a password.

微信里搜索「一点守护」Search WeChat for “一点守护”
⏱
请在 1 小时内完成绑定。为了安全，这个不用密码的 WiFi 只开 1 小时，到时自动关闭；过了时间，把路由器断电再开，会再开 1 小时。Finish pairing within 1 hour. For safety, this open WiFi closes automatically after an hour. If you miss it, power-cycle the router to get another hour.
🔑
路由器管理页和 SSH 的 root 密码会跟着家长 WiFi 密码走。出于安全考虑：root 没有密码时，连上家里网络的人都能登录路由器管理页，改掉或关掉一点守护的设置。所以原来没设 root 密码的，绑定后自动设成家长 WiFi 密码，以后在小程序里改家长 WiFi 密码也会跟着改，解除绑定时清空；自己设过 root 密码的不动。The root password (web admin and SSH) follows the parents’ WiFi password. This is for safety: with no root password, anyone on your home network could log in to the router’s web admin and change or turn off Doti’s settings. So if root had no password, pairing sets it to the parents’ WiFi password; changing that password in the mini program changes root too, and unpairing clears it. A root password you set yourself is left alone.

6核对安装包Verify the package可选optional

安装包由 GitHub Actions 从公开代码自动构建，发布页附有 SHA256SUMS。算一下下载文件的 SHA256，和它一致就说明是公开构建的同一个文件：Packages are built by GitHub Actions from the public code, and each release ships a SHA256SUMS file. If your download’s SHA256 matches, it’s the exact file built in public:

路由器上 / Mac / LinuxRouter / Mac / Linux
sha256sum /tmp/doti.ipk
Windows
certutil -hashfile 文件名.ipk SHA256

也可以下载源码，执行 python3 build.py 自己打包，得到的文件和发布页的一模一样。You can also build it yourself with python3 build.py from the source — you’ll get a byte-identical file.
